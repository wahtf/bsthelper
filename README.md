# BstHelper

The Beastmaster bestiary as a 50-slot grid, a gold box around the beasts you are high enough to capture but
have not, and a ride to whatever you click. `/bst`

`Travel/` is the travel engine from [WahTools](https://github.com/Brappp/WahTools), AGPL-3.0, carried over
with only its namespace changed. Fix it there, not here.
